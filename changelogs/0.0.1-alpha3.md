# Changelog of 0.0.1-alpha3

## Added

- Event bus: generic event system with typed contexts, priority-ordered
  handlers, and a nop-handler embed for partial implementations. Events
  dispatched for player lifecycle (join/quit/chat/command), blocks
  (break/place/interact), items (use), and combat (attack/hurt/death/respawn).

- Task scheduler: PocketMine-style tick scheduler with delayed and repeating
  tasks, mutex-guarded for cross-thread use, heartbeat-driven at 20 TPS.

- Entity system: non-player actors (mobs, projectiles) with pluggable
  behaviours (dragonfly model), a name-to-factory registry, and a mutex-guarded
  manager. Arena snapshot and restore for rollback. Spawn via `/summon` or the
  server API.

- Plugin system: in-tree plugins get one `Api` on enable to register commands,
  event listeners, and scheduled tasks. Built-in plugins wired at startup.

- Multi-world: create, load, unload, and delete worlds at runtime via `/world`
  commands and the Hub API. LevelDB-backed storage with safe handle closure and
  path-traversal protection. Deletion refuses the default world and worlds with
  active players.

- Generators and dimensions: world generators and dimension types (Overworld,
  Nether, End) with configurable properties. Dimension-change freeze fixed.

- Nether portal: obsidian frames (4×5 to 23×23) lit with flint and steel
  create portal blocks. Portal blocks self-destruct when a non-corner frame
  block is broken (water/lava source placement also deactivates them).
  Players standing in a portal are teleported between Overworld and Nether
  after a 4-second delay (instant in Creative mode). Coordinate mapping
  follows vanilla rules (X/Z ÷8 to Nether, ×8 to Overworld, Y unchanged).
  A destination portal is searched for within 128 blocks before generating
  a new obsidian frame with interior portal blocks and a safety platform.
  The Nether world is auto-created on first portal use.

- Block system: blocks with their own behaviour classes, placement hardening,
  and interaction hooks. Block pick and consume item paths corrected.

- Item system expansion: item drop entities spawn on block breaks and
  inventory drops; drop/pickup works across all input paths. Item and block
  hooks for custom behaviour. Custom items, blocks, entities, and enchantments
  supported.

- Improved `/give` command: vanilla-style behaviour with item enum
  autocomplete and target selectors.

- `/msg` command: private messaging with `tell`, `whisper`, and `w` aliases.

- Potions: splash, lingering, and drinkable potions with area effect clouds
  and effect particle colours.

- Configurable difficulty: difficulty (peaceful/easy/normal/hard) set via
  `vedrock.yml` and changeable at runtime.

- Vanilla effects: status effects with proper durations, levels, and particle
  colours.

- Light engine: server-side light-level computation for blocks and sky.

- Chunk block-state upgrader: schema-driven upgrader (df-mc/worldupgrader
  model) with versioned upgrade steps (rename, meta-to-state, value remap)
  applied on chunk load.

- Liquid engine: water flow and spreading with vanilla-style rules.

- Protocol encryption: Minecraft Bedrock packet encryption for secure
  connections.

- Resource packs: client resource pack distribution with validation.

- Modal forms: server-driven modal dialogue forms sent to clients.

- Player view: narrow `View` interface for "acts like a player" capabilities
  (identity, permission, messaging, movement, inventory, UI). Shared across
  commands, events, and lower layers.

- Crash report writer: automatic crash dumps with stack traces written to
  disk.

- Setup wizard: first-run configuration walkthrough.

- Docker support: multi-arch Docker images with CI publish workflow.

- Generated vdocs: V documentation generated and committed for IDE support.

- Localization: French, German, and Turkish translations added.
  Crowdin integration for community-contributed translations.

- Discord community link added to README.

## Fixed

- Dimension change freeze: players no longer hang when switching dimensions.
- Inventory: drop and pick up items now works across all input paths
  (keyboard, controller, touch).
- V 0.5.2 build errors and deprecation warnings resolved.
- Region and bounding-box volume computed in i64 to prevent int32 overflow.
- Entities killed between ticks are now properly despawned.
- Operator permissions and abilities correctly applied.
- Block pick requests return the correct item.

## Changed

- Player view refactored into `server/player/` with a capability-based
  `View` interface. `cmd.Sender` embeds `View` rather than duplicating it.
- Transport interface extracted from `NetworkSession` for cleaner
  abstraction.
- Actor-based concurrency model: cross-session gameplay state mutations
  go through a `WorldJob` channel drained by a single actor thread.
- Codebase migrated to V 0.5.2 and restructured under `server/` with
  clear subpackage boundaries.
